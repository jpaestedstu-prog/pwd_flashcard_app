1. Getting the app onto devices

  1. Download the APK once from the download page (69 MB).
  2. Copy it to every classroom device with a USB drive, SD card, or file sharing — no internet needed on the students' devices.
  3. On each device: open the APK → allow "install unknown apps" if asked → Install.
  4. The app stores everything on the device. Re-installing an update keeps all profiles and progress.
💡 Devices shared by several pupils? That's the normal case — FlashLearn supports many profiles on one device, and each child's progress stays separate.

2. Create your Teacher profile and class

  1. Open the app → Add New Profile → choose Teacher.
  2. From your teacher dashboard, create a class. The app generates a short class code.
  3. Write the class code on the board — students (or you) enter it when creating their Student profiles.
  4. Students who join with your code appear automatically in your class list and reports.
🔒 You can set a PIN on your Teacher profile (Settings → Profile → Set PIN) so pupils can't open your dashboard.

3. Set up each Student profile

When creating a Student profile you can record the learner's age and, if applicable, a disability. Choosing one pre-configures the whole app — you can still fine-tune everything in Settings afterwards.

PresetWhat the app turns on
👁️ Visual impairmentHigh-contrast theme, larger text, voice-guided navigation, spoken words everywhere
👂 Hearing impairmentFilipino Sign Language content first, picture-led cards, visual-only games
🦽 Motor impairmentGaze control & voice commands (uses camera/microphone), extra-large touch targets
🧠 Cognitive / learning disabilityDyslexia-friendly font, calm reduced-motion screens, adaptive difficulty, gentle pacing

4. Teaching with FlashLearn

🃏 Flashcards (Cards tab)

  • 10 decks · 177 words, each with picture, real photo, English & Filipino audio, and FSL.
  • Great for guided vocabulary time: project one device, or let pairs explore a deck.

🎮 Games (Games tab)

  • Each game has Easy / Medium / Hard — start Easy, level up when ready.
  • Play Together is a two-player race on one screen — perfect for pair work.
  • Tracing and Spelling Bee double as fine-motor and phonics practice.

📚 Stories (Stories tab)

  • Short bilingual stories reuse deck vocabulary; comprehension questions earn stars.
  • The harder story in each category unlocks after the easy one — a built-in reading ladder.

🌟 Daily Challenge (Home)

  • One quick question a day — a lovely 5-minute class opener.

5. Tracking progress

  • The Progress tab shows each learner's words mastered, streaks, stars, and per-deck bars.
  • Certificates can be shown or printed when a learner reaches milestones.
  • Your teacher dashboard aggregates the whole class — spot who needs help at a glance.
  • Use notes to leave encouragement that parents can read from a Parent profile.

6. Accessibility cheat-sheet

If a learner…Try turning on…
squints, sits very close to the screenHigh Contrast + font size L/XL (Settings → Accessibility)
is Deaf or hard of hearingRely on FSL buttons on cards + visual games; skip pronunciation games
struggles to tap small buttonsGaze Control and Voice Commands (Settings → Gaze Control; needs camera/mic permission)
reverses letters, tires when readingDyslexia-friendly mode (cream background, Lexend font, wide spacing)
is distracted or overwhelmed by motionReduced Motion; consider Focus Mode and shorter sessions
can't yet read menusVoice-Guided Navigation (reads screens aloud)

7. Classroom tips

  • Everything works offline — no Wi-Fi worries during class.
  • Charge tablets beforehand; the app keeps the screen awake during activities.
  • Rotate "device captains" who hand out tablets and open the right profile.
  • Celebrate streaks and certificates publicly — the reward system is designed for it.
