1. Getting the app onto devicesPag-install ng app sa mga device

  1. Download the APK once from the download page (73 MB).I-download ang APK nang isang beses mula sa download page (73 MB).
  2. Copy it to every classroom device with a USB drive, SD card, or file sharing — no internet needed on the students' devices.Kopyahin ito sa bawat device sa classroom gamit ang USB drive, SD card, o file sharing — hindi kailangan ng internet sa mga device ng mag-aaral.
  3. On each device: open the APK → allow "install unknown apps" if asked → Install.Sa bawat device: buksan ang APK → payagan ang "install unknown apps" kung tatanungin → Install.
  4. Installing a newer version over the old one keeps every profile and its progress. The app tells Teacher and Parent profiles when a new version is on the website (Settings → Check for updates).Kapag in-install ang mas bagong bersyon sa ibabaw ng luma, mananatili ang lahat ng profile at progreso. Sinasabi ng app sa Teacher at Parent profile kapag may bagong bersyon sa website (Settings → Tingnan kung may update).
  5. Lessons and games work offline. Joining a class, Messages and assigned tests need the internet now and then, and each sign video needs it the first time it plays. What goes online is explained on the Privacy & data page.Gumagana nang offline ang mga aralin at laro. Kailangan paminsan-minsan ng internet ang pagsali sa klase, Messages at mga ibinigay na pagsusulit, at kailangan ito ng bawat sign video sa unang pag-play. Ipinaliliwanag sa pahinang Privacy at datos kung ano ang napupunta online.
💡

Devices shared by several pupils? That's the normal case — FlashLearn supports many profiles on one device, and each child's progress stays separate.Iisang device para sa maraming mag-aaral? Normal lang iyan — sumusuporta ang FlashLearn sa maraming profile sa iisang device, at hiwalay ang progreso ng bawat bata.

2. Create your Teacher profile and classGumawa ng Teacher profile at klase

  1. Open the app → Add New Profile → choose Teacher.Buksan ang app → Add New Profile → piliin ang Teacher.
  2. From your teacher dashboard, create a class. The app generates a short class code.Mula sa iyong teacher dashboard, gumawa ng klase. Gagawa ang app ng maikling class code.
  3. Write the class code on the board — students (or you) enter it when creating their Student profiles.Isulat ang class code sa pisara — ilalagay ito ng mga mag-aaral (o ninyo) kapag gumagawa ng kanilang Student profile.
  4. Students who join with your code appear automatically in your class list and reports.Awtomatikong lalabas sa iyong class list at reports ang mga mag-aaral na sumali gamit ang iyong code.
🔒

You can set a PIN on your Teacher profile (Settings → Profile → Set PIN) so pupils can't open your dashboard.Maaari kang maglagay ng PIN sa iyong Teacher profile (Settings → Profile → Set PIN) para hindi mabuksan ng mga mag-aaral ang iyong dashboard.

3. Set up each Student profileI-set up ang bawat Student profile

When creating a Student profile you can record the learner's age and, if applicable, a disability. Choosing one pre-configures the whole app — you can still fine-tune everything in Settings afterwards.Kapag gumagawa ng Student profile, maaaring itala ang edad ng mag-aaral at, kung naaangkop, ang kapansanan. Ang pagpili nito ay awtomatikong nagse-set up ng buong app — maaari pa ring i-fine-tune ang lahat sa Settings pagkatapos.

4. Teaching with FlashLearnPagtuturo gamit ang FlashLearn

🃏 Flashcards (Cards tab)Flashcards (Cards tab)

  • 13 decks · 177 words, each with picture, real photo, English & Filipino audio, and FSL.13 deck · 177 salita, bawat isa ay may larawan, totoong litrato, English at Filipino audio, at FSL.
  • Great for guided vocabulary time: project one device, or let pairs explore a deck.Mainam para sa guided vocabulary time: i-project ang isang device, o hayaang mag-explore ng deck ang magkapares.

🎮 Games (Games tab)Mga Laro (Games tab)

  • Each game has Easy / Medium / Hard — start Easy, level up when ready.Bawat laro ay may Easy / Medium / Hard — magsimula sa Easy, umangat kapag handa na.
  • Play Together is a two-player race, side by side or online — perfect for pair work.Ang Play Together ay karera ng dalawang manlalaro, magkatabi o online — perpekto para sa pares.
  • Tracing and Spelling Bee double as fine-motor and phonics practice.Ang Tracing at Spelling Bee ay nagsisilbi ring pagsasanay sa fine-motor at phonics.

📚 Stories (Stories tab)Mga Kuwento (Stories tab)

  • Short bilingual stories reuse deck vocabulary; comprehension questions earn stars.Gumagamit ang maiikling kuwento ng bokabularyo mula sa mga deck; ang mga tanong sa pag-unawa ay nagbibigay ng stars.
  • The harder story in each category unlocks after the easy one — a built-in reading ladder.Nabubuksan ang mas mahirap na kuwento sa bawat kategorya pagkatapos ng madali — parang hagdan ng pagbasa.

🌟 Daily Challenge (Home)Daily Challenge (Home)

  • One quick question a day — a lovely 5-minute class opener.Isang mabilis na tanong bawat araw — magandang 5-minutong panimula ng klase.

5. Tracking progressPagsubaybay sa progreso

  • The Progress tab shows each learner's words mastered, streaks, stars, and per-deck bars.Ipinapakita ng Progress tab ang mga salitang natutunan, streaks, stars, at progress bar ng bawat deck para sa bawat mag-aaral.
  • Certificates can be shown or printed when a learner reaches milestones.Maaaring ipakita o i-print ang certificates kapag nakaabot ang mag-aaral sa milestones.
  • Your teacher dashboard aggregates the whole class — spot who needs help at a glance.Pinagsasama-sama ng iyong teacher dashboard ang buong klase — agad makikita kung sino ang nangangailangan ng tulong.
  • Use notes to leave encouragement that parents can read from a Parent profile.Gamitin ang notes para mag-iwan ng mensahe ng suporta na mababasa ng magulang mula sa Parent profile.

6. My Day routines and the app lockMga routine sa My Day at ang app lock

My Day is a picture schedule you build for one learner — brush teeth, lunch, reading time — which they follow on their own tablet.Ang My Day ay larawang iskedyul na inihahanda mo para sa isang mag-aaral — magsipilyo, tanghalian, oras ng pagbasa — na sinusunod nila sa sarili nilang tablet.

  1. Open your Teacher Dashboard → Today's Routines → tap the learner. Start from one of the ready-made templates or build your own, one step at a time: pick an activity, its time and how long it lasts.Buksan ang Teacher Dashboard → Today's Routines → i-tap ang mag-aaral. Magsimula sa isa sa mga handang template o gumawa ng sarili, isang hakbang bawat pagkakataon: pumili ng gawain, ang oras nito at kung gaano katagal.
  2. The learner sees each step with a picture, spoken words and, for Deaf learners, the FSL sign. Reminders arrive at each step's time.Nakikita ng mag-aaral ang bawat hakbang na may larawan, binibigkas na salita at, para sa mga Deaf na mag-aaral, ang senyas sa FSL. Dumarating ang paalala sa oras ng bawat hakbang.
  3. App lock (Students and Children): you can make a step lock the app for its length, so the tablet shows the step and a countdown instead of games. The first time, allow Display over other apps on the learner's tablet when the app asks. Steps finish on the clock — the learner doesn't have to press anything.App lock (Students at Children): maaari mong gawing nagla-lock ng app ang isang hakbang habang tumatagal ito, kaya ang hakbang at countdown ang ipinapakita ng tablet sa halip na mga laro. Sa unang pagkakataon, payagan ang Display over other apps sa tablet ng mag-aaral kapag nagtanong ang app. Natatapos ang mga hakbang ayon sa oras — hindi kailangang may pindutin ang mag-aaral.
  4. From your dashboard you can pause a step, add time, unlock the tablet for 30 minutes or excuse a step for today, and copy a routine to other learners or a whole class.Mula sa iyong dashboard, maaari mong i-pause ang isang hakbang, dagdagan ang oras, i-unlock ang tablet nang 30 minuto o i-excuse ang hakbang ngayong araw, at kopyahin ang routine sa ibang mag-aaral o sa buong klase.
💡

Player profiles get My Day as a simple checklist they build and tick themselves — there is no lock.Sa Player na profile, ang My Day ay simpleng checklist na sila mismo ang gumagawa at nagtsi-tsek — walang lock.

7. Pre- and post-testsPre-test at post-test

  1. On your home screen, under More → Assessments & Progress, open Assessments → Assign → Class Pre-Test, then tick your students (Select All picks everyone). Each learner finds it under Assigned to You.Sa iyong home screen, sa More → Assessments & Progress, buksan ang Assessments → Assign → Class Pre-Test, saka i-tsek ang iyong mga mag-aaral (Select All para piliin ang lahat). Makikita ito ng bawat mag-aaral sa Assigned to You.
  2. After the learning period, assign the Class Post-Test. It uses the same questions, so the Class Report can show each learner's gain and which items and categories improved.Pagkatapos ng panahon ng pag-aaral, ibigay ang Class Post-Test. Pareho ang mga tanong, kaya maipapakita ng Class Report ang pag-unlad ng bawat mag-aaral at kung aling tanong at kategorya ang umangat.
  3. Retakes are locked by default, so a learner cannot sit a test twice on their own. An assigned test always opens. To allow retakes for a class: Manage Classes → the class's ⋮ menu → Allow test retakes.Naka-lock ang pag-ulit sa simula, kaya hindi maaaring ulitin ng mag-aaral ang pagsusulit nang mag-isa. Palaging nabubuksan ang ibinigay na pagsusulit. Para payagan ang pag-ulit sa isang klase: Manage Classes → ⋮ menu ng klase → Allow test retakes.
  4. Questions can carry pictures, sounds and FSL videos, and learners who do not read yet can answer by picture — or by recording a video to sign or say the answer, which you then mark.Maaaring may larawan, tunog at FSL video ang mga tanong, at ang mga mag-aaral na hindi pa nakakabasa ay maaaring sumagot sa pamamagitan ng larawan — o mag-record ng video para i-senyas o sabihin ang sagot, na ikaw ang magmamarka.
📶

Tablets need the internet to receive an assigned test and to send the answers back. Connect them for a moment before and after the test.Kailangan ng internet ng mga tablet para matanggap ang ibinigay na pagsusulit at maipadala pabalik ang mga sagot. Ikonekta muna sandali bago at pagkatapos ng pagsusulit.

8. MessagesMessages

  • Open Messages from your home screen to write to a learner, their parent, or your whole class at once.Buksan ang Messages mula sa iyong home screen para sumulat sa isang mag-aaral, sa kanilang magulang, o sa buong klase nang sabay-sabay.
  • Learners can message friends with a composer made for them — pictures and short sign videos as well as words. Photos and videos are deleted 7 days after sending.Maaaring magmensahe ang mga mag-aaral sa kaibigan gamit ang composer na ginawa para sa kanila — larawan at maiikling sign video, hindi lang salita. Nabubura ang mga larawan at video 7 araw pagkatapos ipadala.
  • Anyone can block someone, and a learner's report reaches their teacher or parent. A child in a home group needs their parent's approval before a new friend can message them.Maaaring i-block ng sinuman ang isang tao, at ang report ng mag-aaral ay nakakarating sa kanilang guro o magulang. Kailangan ng pahintulot ng magulang bago makapagmensahe ang bagong kaibigan sa batang nasa home group.

9. Deleting profiles and dataPagbura ng mga profile at datos

  1. To delete a learner who has left: on the tablet that holds their profile, open a Teacher or Parent profile → Settings → Data → Manage Profiles → delete. Their progress, test results, routines and messages are deleted online too.Para burahin ang mag-aaral na umalis na: sa tablet kung nasaan ang kanilang profile, magbukas ng Teacher o Parent profile → Settings → Data → Manage Profiles → burahin. Mabubura rin online ang kanilang progreso, resulta ng pagsusulit, routine at mga mensahe.
  2. To close a class: Manage Classes → the class's ⋮ menu → Delete class. Do this before deleting your own Teacher profile — deleting a profile does not remove its classes.Para isara ang isang klase: Manage Classes → ⋮ menu ng klase → Delete class. Gawin ito bago burahin ang sarili mong Teacher profile — hindi naaalis ang mga klase kapag binura ang profile.
  3. Uninstalling the app does not delete the online copy. Full details are on the Privacy & data page.Hindi nabubura ang kopya online kapag in-uninstall ang app. Nasa pahinang Privacy at datos ang buong detalye.

11. Classroom tipsMga tip sa classroom

  • Lessons work offline — no Wi-Fi worries during class. Connect once before class so assigned tests, routines and new sign videos arrive.Gumagana nang offline ang mga aralin — walang aalalahaning Wi-Fi sa klase. Kumonekta nang isang beses bago ang klase para dumating ang mga ibinigay na pagsusulit, routine at bagong sign video.
  • Charge tablets beforehand; the app keeps the screen awake during activities.I-charge ang mga tablet bago ang klase; pinapanatiling gising ng app ang screen habang may aktibidad.
  • Rotate "device captains" who hand out tablets and open the right profile.Magpalit-palit ng "device captains" na mamimigay ng tablet at magbubukas ng tamang profile.
  • Celebrate streaks and certificates publicly — the reward system is designed for it.Ipagdiwang ang streaks at certificates sa harap ng klase — para diyan ginawa ang reward system.
  • Found a bug or have a request? Use the feedback form — no account needed.May nakitang bug o may kahilingan? Gamitin ang feedback form — walang kailangang account.
